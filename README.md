# 펜션 영업 행사지도

2026년 전국 지역축제(문화체육관광부 지역축제 목록 656건 + 다가올 겨울 시즌 추가 조사 19건)를 지도와 목록으로 보고, 행사별 메모를 남기는 개인용 페이지입니다.

## 실행

폴더 안의 **`행사지도 켜기.command`를 더블클릭**하면 서버가 켜지고 브라우저가 열립니다. 끌 때는 뜬 터미널 창을 닫으면 됩니다. 이미 켜져 있을 때 다시 더블클릭하면 브라우저만 엽니다.

터미널에서 직접 실행하려면:

```bash
cd ~/Desktop/pension-event-map
python3 serve.py
```

- 노트북: http://localhost:8080
- 휴대폰: 같은 와이파이에서 실행 화면에 나오는 `http://192.168.x.x:8080` 주소로 접속
- 종료: 터미널에서 Ctrl+C

처음 실행할 때 macOS가 "Python이 데스크탑 폴더에 접근" 또는 "들어오는 연결 허용"을 물으면 허용해야 합니다.

## 공개 사이트

- 주소: https://tls123qwe.github.io/pension-event-map/ (GitHub Pages, 무료)
- 누구나 볼 수 있습니다. 메모는 보는 사람 각자의 브라우저에만 저장되어 서로 보이지 않습니다.
- **올라가지 않는 파일**(.gitignore): `memos.json`(내 메모), `data/private.js`(영업 메모·상품 아이디어), `data/backup/`
- 영업 메모는 `data/private.js`에 있어서 내 노트북에서 열 때만 카드에 보입니다.

## 주간 업데이트 (자동)

- 매주 월요일 오전 9시에 GitHub가 `update.py`를 돌려 새 행사·바뀐 일정·새로 생긴 공식 사이트를 반영하고 공개 사이트에 올립니다.
- 바로 돌리고 싶으면 GitHub 저장소의 Actions 탭 → '주간 행사 업데이트' → Run workflow.
- 바뀐 내용은 `data/update-log.md`에 쌓입니다.
- 내 노트북 데이터는 `행사지도 켜기.command`를 더블클릭할 때 자동으로 받아옵니다(`git pull`).
- 노트북에서 `python3 update.py`를 직접 돌리지 마세요. GitHub 쪽 업데이트와 겹쳐서 받아오기가 실패할 수 있습니다. 직접 돌려야 할 때는 돌린 뒤 `git commit`, `git push`까지 해야 합니다.
- 직접 추가한 행사(2027년 겨울 행사 등)는 그대로 두고, 문체부에 같은 행사가 올라오면 '중복 후보'로 기록됩니다.

## 메모

- 행사 카드를 펼쳐 '내 메모'에 적거나 별표(관심)를 누르면 자동 저장됩니다.
- 상단 '메모장'에는 행사와 상관없는 메모를 적을 수 있고, 메모를 남긴 행사 목록도 모여 있습니다.
- serve.py로 열면 메모가 이 폴더의 `memos.json`에 저장되어 노트북과 휴대폰에서 같이 보입니다. 같은 메모를 두 기기에서 고치면 나중에 고친 쪽이 남습니다.
- index.html을 파일로 직접 열면 메모는 그 브라우저에만 저장됩니다. 메모장의 '내보내기/가져오기'로 옮길 수 있습니다.
- `memos.json`을 가끔 다른 곳에 복사해 두면 백업이 됩니다.

## 파일

- `index.html` 화면
- `data/events.js` 행사 데이터 (update.py 가 갱신)
- `data/private.js` 영업 메모 (비공개)
- `update.py` 주간 업데이트, `.github/workflows/update.yml` 자동 실행 설정
- `data/korea.js` 시도 경계
- `serve.py` 로컬 서버 + 메모 저장

## 주의

- 같은 와이파이에 있는 사람이면 누구나 접속해 메모를 볼 수 있습니다. 카페 같은 공용 와이파이에서는 서버를 켜 두지 마세요.

- 지도 라이브러리(Leaflet)와 글꼴은 인터넷에서 불러오므로 인터넷 연결이 필요합니다.
